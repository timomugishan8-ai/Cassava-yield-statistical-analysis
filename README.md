# Cassava-yield-statistical-analysis
## Project Overview

This project investigates factors associated with cassava yield using
statistical analysis and data visualization in R.

The analysis focuses on identifying relationships between agricultural
variables and cassava yield, with particular attention to fertilizer
application, tillage methods, and relationships between continuous and
categorical variables.

## Objectives

- Clean and prepare the cassava yield dataset
- Identify and handle missing values and potential outliers
- Explore relationships between variables
- Apply appropriate statistical tests
- Visualize relationships using appropriate plots
- Interpret statistical results and draw evidence-based conclusions

## Tools & Technologies

- R
- RStudio
- R Markdown
- ggplot2
- dplyr
- tidyr
- Statistical hypothesis testing

## Analysis Performed

### 1. Data Cleaning
- Missing-value assessment
- Outlier investigation
- Winsorization where appropriate
- Data transformation where necessary

### 2. Exploratory Data Analysis
- Distribution analysis
- Boxplots
- Scatterplots
- Bar charts
- Relationship exploration

### 3. Statistical Analysis

The analysis examines:

- Continuous vs Continuous relationships
- Continuous vs Categorical relationships
- Categorical vs Categorical relationships
- Hypothesis testing
